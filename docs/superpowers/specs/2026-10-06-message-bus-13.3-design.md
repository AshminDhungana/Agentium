**Date:** 2026-10-06  
**Status:** Design Phase

## 1. Executive Summary

The MessageBus (`backend/services/message_bus.py`) and WebSocket ConnectionManager (`backend/api/routes/websocket.py`) exist but are **not integrated**. This design bridges them via Redis Pub/Sub fan-out, enabling:

| TODO Item | Solution |
|-----------|----------|
| **13.3.1** — Dispatch to correct WebSocket clients | MessageBus publishes to `ws:broadcast` / `ws:user:{username}`; ConnectionManager subscribes and forwards to local sockets |
| **13.3.2** — Cross-worker event distribution | Redis Pub/Sub automatically fans out to all worker processes |
| **13.3.3** — Per-user/room filtering | Per-user channels (`ws:user:{username}`) + future room channels (`ws:room:{room_id}`) |
| **13.3.4** — Replay on reconnection | Per-user Redis Streams (`ws:user:{username}:history`) store last 500 events; `/ws/replay` returns missed events since timestamp |

## 3. Detailed Design

### 3.1 Redis Pub/Sub Channels

| Channel | Purpose | Publishers | Subscribers |
|---------|---------|------------|-------------|
| `ws:broadcast` | Global events (system_alert, agent_status, vote_update, etc.) | MessageBus, ConnectionManager.emit_* | All ConnectionManagers |
| `ws:user:{username}` | User-targeted events (chat_message, task_update for user's tasks) | MessageBus | ConnectionManager for that user |
| `ws:room:{room_id}` | Room events (channel messages) — **future** | MessageBus | ConnectionManagers with users in room |

### 3.2 MessageBus Changes

**New method in `MessageBus` class:**

```python
async def publish_to_websocket(
    self,
    event: Dict[str, Any],
    usernames: Optional[List[str]] = None,
    room_ids: Optional[List[str]] = None,
    persistent: bool = True
) -> None:
    """
    Publish event to WebSocket clients via Redis Pub/Sub.
    
    Args:
        event: Event dict with 'type' and payload
        usernames: If provided, publish to ws:user:{username} for each
        room_ids: If provided, publish to ws:room:{room_id} for each (future)
        persistent: If True, also append to per-user history streams
    """
    # 1. Global broadcast
    if not usernames and not room_ids:
        await self._redis.publish("ws:broadcast", json.dumps(event))
    
    # 2. Per-user
    if usernames:
        for uname in usernames:
            await self._redis.publish(f"ws:user:{uname}", json.dumps(event))
            if persistent:
                await self._append_user_history(uname, event)
    
    # 3. Per-room (future)
    if room_ids:
        for rid in room_ids:
            await self._redis.publish(f"ws:room:{rid}", json.dumps(event))

async def _append_user_history(self, username: str, event: Dict[str, Any]) -> None:
    """Append event to per-user history stream (maxlen=500)."""
    stream_key = f"ws:user:{username}:history"
    await self._redis.xadd(stream_key, {"data": json.dumps(event)}, maxlen=500, approximate=True)
```

**Integration points in existing MessageBus methods:**

- `broadcast_from_head()` → call `publish_to_websocket()` after publishing to agent streams
- `route_up()` / `route_down()` → if recipient is a user (not agent), call `publish_to_websocket()`
- New helper: `get_usernames_for_agent(agent_id)` → query DB for users who "own" this agent

### 3.3 ConnectionManager Changes

**In `ConnectionManager.__init__`:**
```python
self._pubsub: Optional[redis.client.PubSub] = None
self._pubsub_task: Optional[asyncio.Task] = None
self._user_channels: Set[str] = set()  # Track subscribed ws:user:{username}
```

**New methods:**
```python
async def _ensure_pubsub(self):
    """Lazy-init Pub/Sub subscription to ws:broadcast."""
    if self._pubsub is None:
        self._pubsub = (await self._get_redis()).pubsub()
        await self._pubsub.subscribe("ws:broadcast")
        self._pubsub_task = asyncio.create_task(self._listen_pubsub())

async def subscribe_user(self, username: str):
    """Subscribe to per-user channel when user connects."""
    await self._ensure_pubsub()
    channel = f"ws:user:{username}"
    if channel not in self._user_channels:
        await self._pubsub.subscribe(channel)
        self._user_channels.add(channel)

async def unsubscribe_user(self, username: str):
    """Unsubscribe from per-user channel when user disconnects."""
    if self._pubsub:
        channel = f"ws:user:{username}"
        if channel in self._user_channels:
            await self._pubsub.unsubscribe(channel)
            self._user_channels.discard(channel)

async def _listen_pubsub(self):
    """Background task: forward Pub/Sub messages to local WebSocket connections."""
    try:
        async for message in self._pubsub.listen():
            if message['type'] == 'message':
                event = json.loads(message['data'])
                channel = message['channel']
                
                # Determine target: global, user, or room
                if channel == "ws:broadcast":
                    await self._broadcast_local(event)
                elif channel.startswith("ws:user:"):
                    username = channel.split("ws:user:", 1)[1]
                    await self.send_personal_message(event, username)
                elif channel.startswith("ws:room:"):
                    # Future: forward to all users in room
                    pass
    except Exception as e:
        logger.error(f"[ConnectionManager] Pub/Sub listen error: {e}")
```

**Modify existing `authenticate()` and `disconnect()`:**
```python
# In authenticate(), after successful auth:
await self.subscribe_user(username)

# In disconnect():
await self.unsubscribe_user(username)
```

### 3.4 Replay Endpoint Enhancement

**Current:** `GET /ws/replay?since=<timestamp>` → returns last 100 from `agentium:ws:buffer` (global)

**Enhanced:** `GET /ws/replay?since=<timestamp>&username=<username>` → returns missed events from `ws:user:{username}:history` stream

```python
@router.get("/replay")
async def replay_events(
    since: str,
    username: Optional[str] = None,  # NEW: per-user replay
    current_user=Depends(get_current_user)
):
    # Auth: users can only replay their own events (unless sovereign)
    target_user = username or current_user["username"]
    if target_user != current_user["username"] and current_user["role"] != "sovereign":
        raise ForbiddenError("Cannot replay other users' events")
    
    r = await manager._get_redis()
    stream_key = f"ws:user:{target_user}:history"
    
    # Read from stream since timestamp
    events = await r.xread({stream_key: since}, count=500)
    result = []
    for stream, entries in events:
        for msg_id, fields in entries:
            result.append(json.loads(fields["data"]))
    
    result.sort(key=lambda x: x.get("timestamp", ""))
    return {"events": result}
```

## 4. Event Flow Examples

### Example 1: System Alert (Global)
```
AlertManager detects high memory
    │
    ▼
emit_system_alert() → manager.broadcast()
    │
    ▼
ConnectionManager.broadcast() 
    ├── Push to Redis list "agentium:ws:buffer" (existing)
    ├── Publish to "ws:broadcast" (NEW)
    │
    ▼ (on all workers)
ConnectionManager._listen_pubsub() receives
    │
    ▼
Forward to ALL local WebSocket connections
```

### Example 2: Task Update (Per-User)
```
TaskExecutor completes task for user "alice"
    │
    ▼
emit_task_update() → manager.broadcast() 
    │
    ▼
MessageBus.publish_to_websocket(event, usernames=["alice"])
    │
    ▼
Redis: PUBLISH "ws:user:alice" + XADD "ws:user:alice:history"
    │
    ▼ (on worker where alice is connected)
ConnectionManager._listen_pubsub() receives on "ws:user:alice"
    │
    ▼
send_personal_message(event, "alice") → alice's WebSocket
```

### Example 3: Reconnection Replay
```
User "bob" reconnects after 30s offline
    │
    ▼
WebSocket onopen → send auth → receive "system" welcome
    │
    ▼
_handlePong() → _fetchReplay()
    │
    ▼
GET /ws/replay?since=<last_timestamp>&username=bob
    │
    ▼
Read from "ws:user:bob:history" stream
    │
    ▼
Inject missed events into local onmessage handler
```

## 5. Error Handling & Edge Cases

| Scenario | Handling |
|----------|----------|
| Redis Pub/Sub connection lost | ConnectionManager re-subscribes on next `_ensure_pubsub()` call |
| User connects, no history stream exists | `xread` returns empty — graceful |
| Sovereign replays another user's events | Allowed via role check in endpoint |
| MessageBus not initialized | `publish_to_websocket` checks `self._redis` and connects if needed |
| Duplicate events on replay | Frontend dedup set (`_processedIds`) filters by `message_id` |
| Worker crashes, misses Pub/Sub | Events persisted in per-user history streams — replay catches up |

## 7. Migration Path

1. **Phase 1:** Add `publish_to_websocket()` to MessageBus, wire into `broadcast_from_head()`
2. **Phase 2:** Add Pub/Sub listener to ConnectionManager, subscribe on auth
3. **Phase 3:** Enhance `/ws/replay` endpoint for per-user history streams
4. **Phase 4:** Update frontend replay API and store
5. **Phase 5:** Add tests, verify cross-worker with 2+ backend workers

## 9. Out of Scope

- Room-based filtering (`ws:room:{room_id}`) — defer to future channel work
- Message acknowledgment / exactly-once delivery — at-least-once via replay is sufficient
- Horizontal scaling beyond Redis Pub/Sub — current design handles 10+ workers
